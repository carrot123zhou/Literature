# 离线基准：结构校对复核模式与目录来源（2026-10-14）

> 一句话：**在同一份真实文档上，把“全量双遍 + 模型核对目录”的自定义改为“第一遍定案 + 固定比例抽查 + 本地目录直接采信”，模型请求数 -50%~-59%、输入字符 -43%~-52%、必须逐条作答的条数 -48%~-52%。**

## 1. 范围与边界

- 只读真实库；把 `document.json` 复制到临时 `ProjectStore`，用 mock provider 跑**真实代码路径**
  `run_structure_job`。**不调用任何模型、不写真实库、不改 raw、不建前端、不提交 MinerU 任务。**
- 脚本：`tests/manual/structure_review_mode_benchmark.py`（默认预览；`--out` 写 JSON）。
  原始数据：`docs/verification/structure-review-mode-2026-10-14.json`。
- 指标含义：`in_chars` = 请求体 + system 提示字符数（输入侧代理）；`rows` = 模型必须逐条作答的
  条数（输出 token 侧代理）。**两者都是代理指标，不是真实账单，也不能替代质量验收。**
- mock 的第一遍规划由文档自身标题层级派生（标题→h{level}，父=前一个更高级标题；其余块→body），
  因此它度量的是**复核策略本身的请求形状**，不代表真实模型的判断质量。

## 2. 结果（同一份文档，改造前 vs 改造后）

改造前 = `proofread_mode=full` + `toc_extraction=model`（即 d7a0cbd 的默认形态）
改造后 = `proofread_mode=sample` + `toc_extraction=auto`（本次默认）

| 文档 | 候选 | 请求 前→后 | 输入字符 前→后 | 逐条作答 前→后 |
|---|---:|---:|---:|---:|
| White Lotus Teachings | 348 | 16 → **7** (-56%) | 443,113 → **247,200** (-44%) | 761 → **366** (-52%) |
| Metropolitan Journal | 230 | 11 → **5** (-55%) | 267,628 → **143,468** (-46%) | 474 → **242** (-49%) |
| On Being Authentic | 58 | 4 → **2** (-50%) | 56,766 → **27,043** (-52%) | 127 → **66** (-48%) |
| Writing and Authority | 529 | 24 → **10** (-58%) | 654,865 → **375,232** (-43%) | 1,114 → **556** (-50%) |
| Making Transcendents | 489 | 22 → **9** (-59%) | 539,340 → **277,662** (-49%) | 991 → **514** (-48%) |

改造后三类模式的对照（`extract_toc=False`，只看复核策略）：

| 模式 | 请求构成 | 说明 |
|---|---|---|
| `full` | N 个规划窗口 + ⌈候选/40⌉ 批复核 | 历史行为，第二遍重新判断绝大多数候选 |
| `sample` | N 个规划窗口 + **1 批抽查** | 默认；抽查 5%（下限 8、上限 40）只做一致性指标 |
| `off` | N 个规划窗口 | 不发第二遍请求 |

## 3. 为什么可以这样改（证据）

- 历史两遍分歧为 0：`docs/verification/structure-context-experiment-2026-10-14.md` 记录 White Lotus
  348 个候选上 role/level/parent 的分歧为 `0/0/0`，而第二遍占墙钟 64%。
- 库内真实作业：`On Being Authentic` 的 `structure_ai` 作业 288.5 s / 99,006 token，其中
  `structure_proofread` 两次共 184 s（64%）；`White Lotus Teachings` 800.5 s / 341,303 token，
  其中第二遍 490.6 s（64%）。
- reasoning 占比：上述 Authentic 作业 reasoning 30,653 token = 全部 token 的 31%，因此结构路径
  默认关思考（与翻译路径一致）。

## 4. 不能据此声称的部分

- **质量未证**：本基准没有真实模型响应，无法证明“第一遍定案”与“两遍”在准确率上等价。
  抽查指标只回答“两遍在不一致”，不回答“谁是对的”。
- 抽查结论被强制排除在建议之外（`QA_REASON`），不改写 `decisions`，因此抽查不会降低质量，
  但也**不会**替人发现并修掉错误。
- 目录来源改为本地采信只对“有显式目录标记页且能解析出条目”的书生效（本库 5/7 命中）；
  `Once upon a future time` 无标记，仍走模型核对。
- 待补：用留出的真实文档跑一次真实模型 A/B（同一本书两种模式，人工比对采纳率），再决定是否
  把 `sample` 保持为默认。
